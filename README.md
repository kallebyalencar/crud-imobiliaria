# Crud Imobiliária

Sistema de imobiliária desenvolvido com PHP puro, seguindo o padrão arquitetural MVC e utilizando PDO para conexão com banco de dados. Projeto acadêmico da disciplina de Backend.

│   └── DAO/

├── routes/

## ⚙️ Como rodar localmente

1. Clone o repositório
2. Coloque na pasta `htdocs` do XAMPP
3. Importe o banco de dados
4. Acesse `http://localhost/crud-imobiliaria/public`

## 🌿 Branches

- `main` → produção
